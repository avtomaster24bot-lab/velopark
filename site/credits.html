Карты и данные

  • Подложка карты — © участники OpenStreetMap, плитки OpenStreetMap; рельеф — OpenTopoMap (CC BY-SA). Библиотека карт — Leaflet.
  • Линии маршрутов каталога — схематичные: проведены через известные опорные точки, большей частью по дорогам OpenStreetMap с помощью маршрутизатора OSRM (routing.openstreetmap.de). Данные OSM распространяются по лицензии ODbL. Линии не являются официальными треками и не подходят для навигации.
  • Профиль высот — модель рельефа Copernicus DEM GLO-90 через Open-Meteo Elevation API (CC BY 4.0). Профиль по схематичной линии — приблизительный, набор высоты по нему обычно занижен.
  • Длины и набор высоты — из официальных сайтов маршрутов и справочников (ссылки — на странице каждого маршрута). Все числа приблизительные (≈).
